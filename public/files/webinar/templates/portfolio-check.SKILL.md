# 포트폴리오 점검

이 파일은 교육용 스킬 템플릿이다. 실습 프로젝트의 `.claude/skills/portfolio-check/SKILL.md`에 복사해 사용한다.

1. 현재 작업 폴더와 점검할 사이트 폴더를 확인한다.
2. plan.md의 완료 기준을 읽는다.
3. 가능한 브라우저 도구로 390px 및 데스크톱 너비를 확인한다. 도구가 없으면 수동 검증 항목을 요청하고 결과를 기다린다.
4. 사례 필터, 이메일 복사와 실패 안내, Tab 이동, 눈에 보이는 포커스를 확인한다.
5. 예시 경력·성과가 실제 정보처럼 보이지 않는지 확인한다.
6. 공개 폴더에 비밀값·개인 문서·조사 메모가 들어 있지 않은지 확인한다. 비밀값을 발견해도 값 자체를 출력하지 않는다.
7. check.md에 통과 / 실패 / 미확인과 근거를 기록한다. 브라우저를 열지 않았다면 시각 검증을 통과로 기록하지 않는다.
8. 자동 배포, 계정 변경, 도메인 구매는 수행하지 않는다.
